## 🚀 Projeto Dev Links

Um projeto desenvolvido em parceria com o pessoal da Rocketseat, por meio do curso Discover, que teve como objetivo a criação de uma página de links completa, pensada especialmente para quem está dando os primeiros passos na programação. 

**Entenda o projeto;**

- Página de links interativa;
- Modo dark e modo light disponível;
- Compatível com `<Windows / Linux / Mac>`.
